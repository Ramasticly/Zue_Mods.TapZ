### 15.1 Flow of an attack, from the command to the end (questions 1–8)

Tags: **[CODE]** verified in `TCBManajer.java` (line = `jogo:N`), **[INFERRED]**, **[UNKNOWN]**. Everything is driven by `TCBManajer.Run` (jogo:29937), called once per rendered GL frame by `AndroidGLRender.onDrawFrame`; there is **no fixed timestep**, the logic runs one tick per frame **[CODE]**.

1. **Pad task md 38** (jogo:25907; md 37 only initialises the pads) reads the virtual pad/touches into `JoyTrig/Joy`, `TouchesCommand`, `_commandButton` through a 3-slot lockstep buffer (`BTDataSet`/`BTSend`/`BTRev`, jogo:1613/1377) **even offline** — a few ticks of input latency **[INFERRED]**.
2. **Input task md 946** (jogo:23730, one per player, prio 13056+p) runs only if `bGameStart && iBackXOffset == 0 && iEventStatus == 0` (jogo:23733). Pad mode: `PlayerKey[p] = Joy`, direction history in `KeyBuf[p][0..3]/KeyBufTime`, `Dash`, `TameCnt` (charge), `Footwork`. Touch mode (`iControlType[p] == 2`): `switch (TouchesCommand)` (jogo:23775); case 1 spawns an AI macro task md 947 (prio 13184+p+2, `_work[5] = _commandButton`) and sets `AICtrl[p] = true`.
3. **Touch macro md 947 → 948 → 953-960** (jogo:23969-24442): `CPUSeqNo` selects a row of HDAT 6 of `ChrGameData[p+3]` (pairs *(command+1, frame count)*, next sequence at byte 8, end flag at byte 9); `SeqKey[command]` (jogo:584) is turned into `PlayerKey/JoyTrig`.
4. **Fighter task md 863/864/872…** (created by `CreatePlayer`, prio 13569+p, jogo:3354). Idle md 872 (jogo:20874) calls `CommonNormal(gw, allowMove, _, allowDash, autoFace, allowAttack)` (jogo:2747). `CommonNormal` calls `CmdCheck(gw, p)` (jogo:2404; returns a code 0–23) and ORs `PlayerAttackFlag[p] |= 1 << code` (jogo:2782).
5. **Command code → `SpecialType` (= the HDAT 4 row = the move number `GOLPE_n`)** inside `CommonNormal` (jogo:3015-3114) **[CODE]**:

   `PlayerAttackFlag` is only a "command seen" bitmask read by `MissionClearCheck` (tutorial); it has **no gameplay effect**. The **move number in the editor (`GOLPE_0…`) is this `SpecialType`**; moves 0/3/6 are the "special 1" slots (ground/air/flying).
6. **Special start md 880** (jogo:21699): `SYNCHRO_DEC(100)` if the current ANO is 40–88; clears `TameCnt`/`PlayerKey`; calls **`StartPlayerAttack`** (jogo:31614-31674); then md 881 → 882. Ultimates go md 923 → 926 → 927 → 928 → 881. `StartPlayerAttack` **[CODE]**: clears `wFlag` bits 1 and 4096, `_SetObj(150+4p)`, sets `PlayerAttack = 1`, `PlayerHitStop = 10`, `DamageHitBack = 0`, `GuardHitBack = 13`, `CancelTime = 0`, `DamageHitActNo[opp] = 0`, `SpecialBulletNumber = 0`; reads the HDAT 4 row `SpecialType` (next section): `SpecialKind[p]` (= ATK_FLAGS), `ANIM_INICIAL`, `BulletAction[p][0..1]`; `AngryOn = true` for SpecialType 14/15; if the current ANO is 40–92 (not 80/89) and the new ANIM_INICIAL ≥ 40 and SpecialType not 9–12 it spawns a chain flash (md 965, effect ANO 8); it sets `objExec.ano = 0` then `_SetAct(acttype, ANIM_INICIAL)` (jogo:31661-31662) — the `ano = 0` makes the same ANO restart.
7. **Attack loop md 882** (jogo:21735), each tick: cancel check (only if `CancelTime > 0 && !(PlayerState & 524288)`, jogo:21739), `PlayerTail`, SEQ/END/grab logic (jogo:21869-21946), then `Game(gw, 883)` runs inline (jogo:21948) while the md stays 882.
8. **`PlayerTail`** (jogo:29714-29899), the common per-tick fighter tail: `DamageMove` knock-back, `GuardCancelTime--`, `_SetXY` from `PlayerXPos/YPos`; if `iHitStop != 0` → `wActFlag |= 4` (freeze) and `CancelTime = 20` when it was 0 (jogo:29777-29783), otherwise unfreeze and decrement `CancelTime` (jogo:29784-29790); `_ActReq` (animation script) + `ChrSePlay` (skipped when md 925); `PlayerXPos/YPos` rebuilt from `objExec`; **hit boxes of type 0 spawn a projectile task md 970** (prio 13312+p, jogo:29808-29878) subject to `BulletAction[p][0] != 0 && BulletNum < 8` (count 3 if `SpecialKind & 4`; spawn position by `SpecialKind` bit 32/64); then `PlayerState &= -50069508` (clears the per-frame flag bits, jogo:29884) and **`CheckOptFlag`** (jogo:29885).
9. **Hit detect md 935** (prio 13728, created at jogo:5677): `CheckObjHit` finds attacker type-2 boxes against defender type-1 boxes; then `DamageChange(gw, att, def, true, true, atk.ano, atk.OptData[0], atk.OptData[1] & 255, atk.wOptFlag)` (jogo:23464); projectile hits use jogo:23424.
10. **`DamageChange`** (jogo:3466-4041) applies guard/damage/reaction (see 15.4, 15.5). The reaction runs in **md 876** (gamedata table, jogo:20983) or **md 877** (attacker's character table, jogo:21259) until `DamageEnd` (jogo:4043) and md 864.
11. **Attacker side**: md 935 sets `tcbPlayer[att].wFlag |= 1` (jogo:23467); next tick md 882 sees it (jogo:21889) and arms SEQ/END switching; when the ANO finishes (`wActFlag & 2`) md 883 → md 864, which calls **`AttackEnd`** (jogo:901-925; call at jogo:20747).

**What `Run`, `Init`, `_ActReqMain` and `CheckOptFlag` are [CODE].** `Run` (jogo:29937): scheduler pass over the task list, then `Draw`. `Init` (jogo:28611): engine start, calls `InitGameData` (jogo:29127). `_ActReqMain` (jogo:31772-32047): the **ANO interpreter** (one pattern per call, see 15.8) — it is **not** an attack function. `CheckOptFlag` (jogo:2112): per-tick processor of the **hit-box action flags** and `wOptFlag` bits (shake, cutscene, teleport, heal, dust…); it does not decide attacks.

**Per-tick order [CODE].** `Run` iterates the task list in ascending priority (ties in creation order): pads (12657/12660) → input md 946 (13056+p) → macro/CPU md 947/951 (13184+) → projectiles md 970/971 (13312+p) → **fighters (13569+p)** → hit effects md 965 (13598) → shadows/auras (13696+) → **hit detect md 935 (13728)** → **cutscene md 996 (13729)** → camera md 19 (13745) → HUD (13808+). So within a tick: input → projectiles → fighters (new patterns load, hit boxes become armed) → hit detect (reads those boxes) → camera. A reaction chosen by `DamageChange` in md 935 starts running on the defender's **next** tick. A task created during the pass with a lower priority than the running one first runs on the next tick (a projectile spawned by a fighter advances one tick later). With `bTaskSkip` (pause) only priorities `0x10xx` run; with `iTaskSleep != 0` or `bActionStop` all `0x3xxx` tasks (12288–16383: fighters, projectiles, hit detect, camera) are skipped (hit-stop of the whole scene, cutscene freezes).

**Ending, interrupting, handing over [CODE].**
- *Normal end*: md 883 (jogo:21950) when `wActFlag & 4 == 0` and the ANO finished (`wActFlag & 2`) → md 864 (`AttackEnd`). Repeat-fire: if `HDAT4[30] > 0` and SpecialType is 0/3/6 and the ANO is not 42, it plays ANO 42 and md 882; repeat while `SpecialBulletNumber < HDAT4[30]`, `wOptFlag & 512` and `JoyTrig & 16640` swap ANO 40/41 (jogo:22012-22028). Airborne when the ANO ends: ANO 89 and md 886. Landing (`Y > ground && iYSpeed > 0`): plays the HDAT 4 landing ANO if non-zero, else `AttackEnd` + ANO 13 + md 893; SE 12 (jogo:21958-21995).
- *SEQ/END chaining (md 882, jogo:21868-21946)*: the alternate hit ANO is `DamageHitActNo[opp]` when `PlayerState & 8388608` (hit flag 38), else `HDAT4[byte 32]`, else `DamageHitActNo[opp]`. Only if the opponent is in md 876/877: `wFlag & 4096` (set by a projectile hit of the same SpecialType, jogo:24560) switches to the alternate ANO; `wFlag & 1` arms `_work[10] = 1`; if the current ANO equals the hit ANO and `_work[10] == 1` then: `ano == SEQ && END != 0` → `_SetAct(END)`; else `SEQ != 0 && ano != SEQ && ano != END` → `_SetAct(SEQ)` (and, when `END != 0`, `_work[10] = 0` re-arms). The pair is ground (bytes 10/12) when `PlayerYPos == 15728640`, else air (bytes 14/16).
- *Grab* (`SpecialKind & 8`, or `& 128` with a hit): when the ANO is ANIM_INICIAL and (`wActFlag & 2` or `wOptFlag & 512`) it plays `ano + 1`, places the opponent at HDAT3[5] px and sets `bScrollLock` (jogo:21927-21945); the grabbed overlay (md 939/940/941) draws HDAT4[byte 24] at the defender and registers into `tcbReqHit[]`.
- *Cancels*: md 879 (normals) and md 882 (specials) allow `CmdCheck` cancels when `CancelTime > 0 && !(PlayerState & 524288)`; SpecialType 9–12 cannot be cancel targets. `CancelTime` is set to 20 by hit-stop (jogo:29778) and by a projectile hit; it counts down on non-hit-stop ticks; a pure whiff leaves it 0 (no cancel).
- *Interruption by damage*: `DamageChange` forces md 876/877 and resets `DamageType/Index/Time`; `PlayerAttack[def] = 0`, `SpecialKind/Type[def] = 0`. Defender projectiles are **not** killed (`BulletNum` untouched).
- *Other state changes*: knock-down md 888 → 889 → 890 → ANO 25, md 894; air normals/fall md 886 → 887 (SE 12) → 893; dash md 891; walls md 932/933 → 934; guard md 908 → 911 (needs Synchro ≥ 100, no ANO 310/312, `iEventStatus == 0`) → 912…915.

**Undocumented blockers [CODE].** md 946 does nothing unless `bGameStart && iBackXOffset == 0 && iEventStatus == 0`; `CmdCheck` returns 0 when `iTimer == 0` and (AI branch) while `DamageMove[p] != 0`; `CommonNormal` ignores everything if `Life[opp] <= 0`; specials need Synchro (`var6 = 0`, or 100 when the current ANO is 40–88; ultimates 100/200, halved by `SynchroPowerUp`; `+100` with `iBackMode`); rage (code 4) needs `!AngryOn && Angry >= 100`; charge refused when `Synchro >= SynchroMax`; normals need `PlayerAttack[p] == 0`; chains need `CancelTime > 0`, no hit flag 27, target not SpecialType 9–12. Data errors that silently abort a move: ANIM_INICIAL absent from the DAC (ends after one tick: `_ActReq` sets `wActFlag |= 2` when `apt == 0`), ANIM_INICIAL = a looping idle ANO (never ends) **[INFERRED]**, HDAT 4 row ≥ rows, **more than 10 boxes in a frame (ArrayIndexOutOfBounds)**, OPT1 class ≥ 5, a character reaction type without a matching HDAT 14+ table, object pool exhaustion (1200 `ObjReq`, 1170 TCB: `_SetAct` returns silently). **[UNKNOWN]**: the trigger of md 898, 909, 921; the meaning of `wOptFlag` 256; whether `tcb.skip` is ever set.
