### 15.8 ANO, MPT, sprites and links (questions 64–71)

**Structure [CODE].** An ANO (`$ANO_n`) in the DAC = `flags` byte (4 = priority byte present, 2 = link block present), `mpt` byte (pattern/frame count, ≤ 255), optional priority, optional links (6 bytes each: x, y, flags|ANO & 4095; ≤ 13, one level), then an offset table of patterns (`jogo:32354-32366`). A pattern (`$MPT_i`) starts with a **flag byte** that says which fields follow, in this order: `0x20` **TIME** (1 byte; **absent ⇒ `time = 0` and the frame never advances**), the **image** short (always present; `-1` = no sprite), `0x01` **MID** (ox, oy shorts), `0x02` **WACTFLAG** word, `0x08` **SE** byte, `0x04` **MOVE** block (mask bits 1/2/4/8 select `xSpeed/ySpeed/xAccel/yAccel`, 32-bit 16.16 each), `0x10` **HITS** block, `0x40` **OPT** block (`wOptFlag` word + 4 bytes `OptData`), `0x80` **RAZ** block (rotation, alpha, x/y zoom + their per-tick adds). `_ActReqMain` (jogo:31772-32047) runs once per tick per object (root and its 13 links).

**Processing of a frame [CODE].** On the tick a pattern is loaded: `time`, `img`, `ox/oy`, `wActFlag &= 0xA000` (only the two sync bits survive) then OR the frame's word; SE (`< 80` → `PushSE(se−1)`: common game sound; `≥ 80` → `var2.se` played by `ChrSePlay` from the character's wav list); **speed zeroed unless `wActFlag & 64`; accel always zeroed**; then the MOVE block loads speeds/accels; hit block rebuilds `hit[]`; OPT block loads `wOptFlag/OptData` (absent ⇒ all 0); RAZ sets rotation/alpha/zoom. On later ticks while `time > 0` (and not frozen by `wActFlag & 4`): tween (`OptData[2] != 0`), move (`x += iXSpeed` mirrored by `wObjFlag & 16`; `y` by bit 32), add accel, `--time`; at 0 the next pattern loads (`pat++`), or `pat = 0` if `wActFlag & 1` (**WACTFLAG bit 1 = loop back to the first frame when this frame ends**), and when `pat >= mpt` the ANO ends (`wActFlag |= 2`).

**WACTFLAG bits [CODE].** `1` loop to frame 0 at the end of this frame · `2` ANO finished (set by the engine) · `4` frozen (engine hit-stop; also checked on the parent) · `16` flip X · `32` flip Y (these two are XORed with `wObjFlag & 48` for drawing and boxes) · `64` keep speed · `0x2000` (8192) follow the parent's position (links) · `0x8000` (32768) follow the parent's frame. Bits `512/1024/2048` are set by the engine in a few places **[UNKNOWN meaning]**. `$TIME: 0`/absent freezes a frame forever (a frozen last frame is a classic way to hold a pose).

**Links [CODE].** A link is another ANO spawned with the parent (`lnk[13]`, one level). It follows the parent when its `wActFlag` has `0x2000` (position) / `0x8000` (frame); with the frame sync, if the parent's `pat` changed the link jumps to the same `pat` and restarts its `time`. Hit boxes/flags inside links are **not processed** (collision and `CheckOptFlag` are root-only), and a link's own links are not created.

**Image, origin, draw order [CODE].** `img` indexes the character's CNV (9 bytes per entry: sheet, x, y, w, h; `DrawImage` jogo:620). `img = -1` (or an ANO without data) draws nothing but the frame still counts time, moves and carries boxes/OPT/SE. The sprite is drawn centred around the object's position offset by `MID` (ox, oy), zoomed/rotated by RAZ. Draw order is a global sort by priority (`prio − iActPrio`, then task priority); a character's ANO may carry `$PRIO`. **Visual vs. collision are independent**: a frame may have a sprite and no boxes, boxes and no sprite, or neither.

**Animation changes during an attack [CODE].** On hit: SEQ/END/`ANIM_AO_ACERTAR` (15.1); landing: `POUSO_AO_ERRAR/ACERTAR` or ANO 13; end of airborne animation: ANO 89; wall/KO/reaction end: ANO 24/25/13/89 by state (15.5). Hit flag **20** (cutscene) spawns task md 996 which plays an ANO from `effect.pac` or the character's pac in parallel and may freeze the opponent, move the camera and force walls (rows of HDAT 13; 15.9).
