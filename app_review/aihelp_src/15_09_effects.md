### 15.9 Effects, sounds, camera (questions 72–76)

**Hit effect and sound [CODE].** After `DamageChange` the game spawns the effect given by `HitEffectActNo[group]` = `{0, 0, 1, 0, -1}` (effect-pack ANO 0 or 1; group 4 none) at `iHitXPos/iHitYPos` through md 965/966 on `ChrGameData[5]` (the `effect` pack), and plays `HitSound[group]` = `{3,4,6,3,7}` (SE 8 when the effect is neither ANO 0 nor 1). Guard uses `GuardEffectActNo` = `{2,2,2,2,-1}` and SE 8. Clash spark = effect ANO 3 + SE 9. These come from the OPT1 **group**, i.e. from the attacker's `$OPT` `d1`, not from HDAT 4.

**Effects created by hit flags [CODE].** Flags 10–17: effect-pack ANO `50 + flag − 10` (dust/smoke). Flags 41–70: `charf` pack ANO `flag − 41 + 3` (bubbles; never mirrored). Flags 71–125: the **character's own DAC**, ANO `201 + flag − 71` (auras/effects; inherit the owner's flip unless the effect's frame has a type-0 box). They live while the flag is present in the owner's current frame (tracked in `AuraAction[player][63]`, md 976/978), at offset `(hit.x, hit.y)` mirrored by facing. `wOptFlag` bits 4096·t (t = 1..15): dust task md 961 at the feet (t 1–5 → bobj ANO 10–14, 6–7 → effect ANO 78–79, ≥ 8 → effect ANO 70+(t−8); +80 when facing left); bit 2048: wall-impact effect (effect ANO 12, SE 6, `CancelTime[opp] = 0`, only after `DamageWall`); bit 1024: `PlayerState |= 1` (hides the background, blocks wall detection).

**Camera, shake, zoom [CODE].** Hit flags 3/4/5 set `iBackShakeType` and `iBackShake = 12` (light/medium/strong shake). Flags 30/31 set action-zoom variables (`iZoomBase`, `iZoomXCenter`, focus time). Hit-focus (md 994/995) zooms on a hit. md 19 is the camera/scroll task (13745): follows the players, clamps them to the screen (15.6), and reacts to `DamageWall` for WALL 1/3. `bActionStop`/`iTaskSleep` pause all gameplay tasks (used by ultimates/cutscenes).

**Sound and voice [CODE].** Frame `$SE < 80`: common game sound `SE−1` via `PushSE`; `≥ 80`: character wav `SE` via `ChrSePlay` (sorted `*.wav`, id 80 = first). Reaction `VOZ > 0`: `Voice(1, player, id)` when the row is entered. Wall impact SE 6, landing SE 12, bounce SE 11.

**Cutscenes (md 996) [CODE].** Created by hit flag 20 (`CheckOptFlag`, jogo:2284; prio 13729): row `id` of the **attacker's HDAT 13** (stride `2*XSize[13]`): [0] actor type (0 = effect pack ANO via `ChrGameData[5]`, 1 = the character's own pac, other = bobj pack), [2] pattern window (kills the task when the attacker passes `pat >= _work[3] + value`), [4] priority mode, [6]/[8] ANO facing right/left, [10] mode (1 = full-screen), [12] freeze the opponent (md 925 until the scene ends: projectiles, auras and grabs also pause), [14] special action 1–15 (3/4/7/9 `ScrollCheckOff`, 5 `iScrollTarget`, 6 `bForceWall`, 7/8/9 `ScreenEdgeOff`, 10–15 teleports to a screen edge). It sets `PlayerState |= 33554432` while it exists.

**What belongs where [CODE].** HDAT 4: which ANOs a move uses (start, projectile, SEQ/END, landing, grab, sub-projectile) and the `ATK_FLAGS`. The ANO frames: sprites, timing, movement, boxes, `$OPT` (damage, reaction code, interpolation), `wOptFlag` bits (windows, dust, wall impact, background), hit-flag actions (shake, zoom, cutscene, teleport, aura/effect spawn, heal, self-damage…). `effect`/`gamedata`: the hit/guard/clash effect ANOs, the reaction tables, the combo-scaling table, the dust/smoke ANOs. **Logic vs. visual**: flags 20 (freeze/camera/walls), 26–28, 32, 34, 37–40, `wOptFlag` 512/1024/2048, ATK_FLAGS and OPT1 groups change gameplay; sprites, `MID`, RAZ, shake (3–5), dust and aura effects (10–17, 41–125) are visual/audio only; zoom (30/31) affects only the camera.
