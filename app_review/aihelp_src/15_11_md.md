### 15.11 MD methods, state machine and variables (questions 82–87)

**Dispatch [CODE].** `Game(gw, md)` (jogo:4755) sends `md` to one of `Game17` (1–24), `Game8` (25–42), `Game9` (43–121), `Game13` (122–183), `Game12` (184–292), `Game14` (293–426), `Game10` (427–628), `Game15` (629–674), `Game1` (675–730), `Game2` (731–795), `Game4` (796–844), `Game11` (845–861), `Game5` (862–895), `Game6` (896–942), `Game7` (943–997), `Game3` (998–1080), `Game16` (1081–1122). Unlisted numbers do nothing. A task changes state with `tcbNow.md = X; tcbNow.lp = 0;`, optionally an inline `Game(gw, X)`; `_TLoop(n, next)` waits n ticks; `_TKill/_TKilx(lo,hi)` kill tasks by priority range; `_TFlag(lo,hi,f)` sets `wFlag`; `_TaskMake(gw, md, prio)` (jogo:32585) inserts into a priority-sorted list (ties in creation order).
